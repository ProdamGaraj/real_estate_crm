Таблица: Термины
Ширины: 24, 76
| Термин | Определение |
|---|---|
| Бронь | Сделка в начальном статусе: объект закреплён за клиентом до даты окончания брони и выведен из продажи |
| График платежей | Разбивка стоимости по договору на платежи с плановыми датами; сумма платежей равна стоимости по договору |
| Заявка | Зарегистрированное обращение клиента с его интересом к приобретению недвижимости; основная единица воронки продаж |
| Клиент | Физическое лицо, с которым работает компания; карточка клиента принадлежит одной компании |
| Компания | Юридическое лицо, работающее в системе; данные и справочники разных компаний изолированы друг от друга |
| Мягкое удаление | Пометка записи удалённой без физического удаления: запись скрывается из списков и отчётов и может быть восстановлена |
| Область видимости | Граница данных, доступных пользователю по разрешению: свои записи, отдел, компания или вся система |
| Объект недвижимости, объект | Квартира, коммерческое помещение, парковочное место, кладовая или коттедж в составе дома |
| Партнёр | Внешняя система (сайт, бот, агентство), обращающаяся к публичному API по API-ключу |
| Разрешение | Сочетание действия, ресурса и области видимости, например «просмотр клиентов своего отдела» |
| Расторжение | Прекращение сделки, по которой прошли платежи или есть подпись клиента; требует документа-основания и влечёт возврат денег |
| Роль | Именованный набор разрешений, назначаемый пользователям |
| Сделка | Договорные отношения с клиентом по одному объекту: от брони до подписанного договора или отмены |
| Справочник | Перечень значений для выбора в формах (статусы заявок, причины отказа, типы платежей и т.п.) |
| Шахматка | Табличное представление объектов дома: подъезды по столбцам, этажи по строкам, статус — цветом ячейки |
