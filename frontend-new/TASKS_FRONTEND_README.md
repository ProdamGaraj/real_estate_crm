# Функционал управления задачами - Frontend

## Обзор
Реализован полноценный UI для управления задачами с интеграцией в систему разрешений.

## Созданные файлы

### API клиент
- **src/api/tasks.ts** - TypeScript API клиент с полным набором функций

### Страницы
- **src/pages/TasksPage.tsx** - Главная страница с 3 вкладками (Список, Канбан, Календарь)
- **src/pages/TaskDetailPage.tsx** - Детальная страница задачи с комментариями и логами

### Компоненты
- **src/components/tasks/TaskListView.tsx** - Таблица задач с DataGrid
- **src/components/tasks/TaskKanbanView.tsx** - Канбан-доска с колонками по статусам
- **src/components/tasks/TaskCalendarView.tsx** - Календарное представление задач
- **src/components/tasks/TaskFilterForm.tsx** - Форма фильтрации задач
- **src/components/tasks/TaskFormDialog.tsx** - Диалог создания/редактирования задачи

### Интеграция
- **src/layouts/RootLayout.tsx** - Добавлен пункт "Задачи" в навигацию с иконкой Checklist
- **src/App.tsx** - Настроены маршруты `/tasks` и `/tasks/:id` с проверкой прав
- **src/utils/permissions.ts** - Добавлен тип ресурса `TASK`

## Основные возможности

### TasksPage (Главная страница)
- **3 вкладки просмотра:**
  - Список - таблица со всеми задачами
  - Канбан - доска с карточками по статусам (NEW, IN_PROGRESS, REVIEW, COMPLETED, CANCELLED, BLOCKED)
  - Календарь - задачи на календаре по дедлайнам

- **Фильтрация:**
  - По статусу (множественный выбор)
  - По приоритету (LOW, NORMAL, HIGH, URGENT)
  - По дате (срок от/до)
  - По поисковому запросу
  - По тегам
  - По просроченным задачам

- **Действия:**
  - Создание новой задачи (кнопка "Создать задачу")
  - Обновление данных
  - Просмотр статистики (всего, мои задачи, просроченные)

### TaskDetailPage (Детальная страница)
- **Информация о задаче:**
  - Название, описание, теги
  - Статус и приоритет
  - Автор и исполнитель
  - Сроки (создана, начата, дедлайн, завершена)
  - Оценка и фактическое время
  - Компания и отдел
  - Наблюдатели

- **Функционал:**
  - Кнопки управления статусом: Начать, Завершить, Отменить
  - Редактирование задачи
  - Удаление задачи
  - Добавление комментариев
  - Просмотр истории изменений (логи)
  - Просмотр подзадач

- **Комментарии:**
  - Добавление новых комментариев
  - Просмотр всех комментариев с автором и временем
  - Поддержка вложений (если загружены)

### TaskFormDialog (Форма создания/редактирования)
- **Поля:**
  - Название* (обязательное)
  - Описание* (обязательное, multiline)
  - Исполнитель* (выбор из списка пользователей)
  - Срок выполнения* (date picker)
  - Приоритет (LOW/NORMAL/HIGH/URGENT, по умолчанию NORMAL)
  - Оценка времени (в часах, decimal)
  - Теги (через запятую)
  - Наблюдатели (множественный выбор пользователей с Autocomplete)

- **Валидация:**
  - Все обязательные поля проверяются
  - React Hook Form для управления формой
  - Отображение ошибок

### TaskKanbanView (Канбан-доска)
- Колонки по статусам задач
- Карточки с информацией:
  - ID и название
  - Теги
  - Исполнитель (аватар)
  - Дедлайн с индикацией просрочки
  - Цветовая индикация по приоритету (левая граница карточки)

- Переход к деталям по клику на карточку

### TaskCalendarView (Календарь)
- Месячное представление
- Навигация между месяцами
- Отображение задач по дедлайнам
- До 3 задач на день (остальные показываются как "+N ещё")
- Выделение сегодняшней даты
- Цветовая индикация просроченных задач

### TaskListView (Таблица)
- **Колонки:**
  - ID
  - Название (кликабельное, просроченные выделены красным)
  - Статус (цветные Chip)
  - Приоритет (цветные Chip)
  - Исполнитель
  - Автор
  - Срок (с индикацией просрочки)
  - Дата создания
  - Компания
  - Теги (до 2 с индикатором "+N")
  - Действия (кнопка редактирования)

- Пагинация (10/25/50/100)
- Клик по строке открывает детали
- Сортировка по всем колонкам

### TaskFilterForm (Фильтры)
- Множественный выбор статусов и приоритетов
- Date pickers для фильтрации по срокам
- Поле поиска по названию/описанию
- Фильтр по тегам
- Фильтр "Просрочено" (Да/Нет/Все)
- Кнопки "Применить" и "Сбросить"

## Интеграция с разрешениями

### Проверки прав:
- **VIEW** - просмотр страниц задач
- **ADD** - создание новых задач (кнопка "Создать")
- **EDIT** - редактирование, изменение статуса
- **DELETE** - удаление задач

### Области действия:
- **OWN** - только свои задачи (где пользователь исполнитель)
- **DEPARTMENT** - задачи своего отдела
- **COMPANY** - задачи всей компании
- **SYSTEM** - все задачи в системе

## Навигация
Пункт меню "Задачи" с иконкой Checklist отображается только для пользователей с правом VIEW на ресурс TASK.

## Маршруты
- `/tasks` - главная страница (требует TASK VIEW)
- `/tasks/:id` - детальная страница (требует TASK VIEW)

## API интеграция
Все запросы используют React Query для:
- Кэширования данных
- Автоматического обновления
- Оптимистичных обновлений
- Обработки ошибок

## Состояние статусов и их переходы
- **NEW** → **IN_PROGRESS** (кнопка "Начать")
- **IN_PROGRESS** → **COMPLETED** (кнопка "Завершить")
- **Любой статус** → **CANCELLED** (кнопка "Отменить")

## Цветовая схема

### Статусы:
- NEW - серый (default)
- IN_PROGRESS - синий (primary)
- REVIEW - голубой (info)
- COMPLETED - зелёный (success)
- CANCELLED - красный (error)
- BLOCKED - оранжевый (warning)

### Приоритеты:
- LOW - серый (#757575)
- NORMAL - синий (#2196f3)
- HIGH - оранжевый (#ff9800)
- URGENT - красный (#f44336)

## Использование

1. Пользователь с правами VIEW на TASK видит пункт меню "Задачи"
2. На главной странице может переключаться между представлениями
3. Применять фильтры для поиска нужных задач
4. Создавать новые задачи (с правом ADD)
5. Открывать детали задачи по клику
6. Изменять статус задачи, редактировать, добавлять комментарии
7. Просматривать историю изменений и подзадачи

## Технический стек
- React + TypeScript

- React Query для работы с API
- React Hook Form для форм
- React Router для навигации
